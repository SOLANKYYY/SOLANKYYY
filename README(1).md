## About me

I'm Om, an AI/ML student who enjoys turning technical ideas into software people can explore and use. My projects span computer vision, crop recommendation, local language-model evaluation, and web applications.

I like working across the full process: understanding the data, experimenting with models, building the interface, and documenting how the system works. Alongside project work, I'm strengthening my foundations in data structures, algorithms, and databases.

## Selected projects

### 01 / RetinaBridge

**Retinal image screening research prototype**

A browser-based workflow connecting patient intake, five-class diabetic retinopathy prediction, Grad-CAM visual explanations, and printable review reports. The project connects MATLAB model development with Python and ONNX inference for web deployment.

`MATLAB` `Python` `Flask` `ONNX Runtime` `OpenCV` `JavaScript`

[Explore the repository →](https://github.com/SOLANKYYY/RetinaBridge) &nbsp; · &nbsp; [Open demo ↗](https://retina-bridge.vercel.app/)

<sub>Research and demonstration prototype; not a clinically validated diagnostic system.</sub>

### 03 / Local LLM Comparison

**Evaluating small language models on the same agricultural data**

A local comparison of DeepSeek-R1 and Llama 3.2 using Ollama. The experiment examines crop predictions, structured JSON responses, and model behaviour on tabular soil and climate inputs.

`Python` `Ollama` `pandas` `LLM Evaluation`

[Explore the experiment →](https://github.com/SOLANKYYY/same-data-llm-comparison)

### 04 / Soil & Crop Recommendation

**Machine learning for crop suitability**

A supervised learning project that uses soil nutrients and environmental measurements to recommend crops. Includes model comparisons, feature analysis, and an interactive terminal prediction workflow.

`Python` `scikit-learn` `pandas` `Random Forest`

[Explore the repository →](https://github.com/SOLANKYYY/ML-Soil-Suitability-Crop-Recommendation-System)
